## Cómo se combinan las fuentes

- **INFURG-SEMES 2012:** orden de trabajo de sus capítulos 18–23: sospecha y valoración inicial → pruebas → tratamiento → destino y seguimiento. Sus capítulos medular y de derivaciones sirven para hacer visibles esas rutas.
- **SEN 2025:** contenido clínico prioritario, incluidos fármacos, dosis, poblaciones, pruebas y excepciones. Las tablas terapéuticas de 2012 no se trasladan para completar huecos de SEN.
- El **destino asistencial** tomado de INFURG se identifica expresamente como tal. No se recuperan sus umbrales de gravedad ni sus tiempos de observación como reglas de alta.
- Si SEN contiene una contradicción, posible errata o pauta incompleta, se señala junto al contenido. Su prioridad entre estas dos fuentes no elimina esas limitaciones.

El [registro de fuentes, cobertura y discrepancias](FUENTES_Y_COBERTURA.md) permite comprobar el origen de cada recorrido y cómo se han resuelto las diferencias. Los cinco temas conservan la cobertura del manual SEN; hongos, parásitos y prionopatías no se recortan para ajustarlos al índice de INFURG.

## Citas y alcance

Cada bloque identifica capítulo, página impresa y página del PDF. Para **SEN**, impresa = PDF + 618; para **INFURG**, impresa = PDF + 144. En los cinco temas, las citas «Fuente: cap.» corresponden a SEN; cualquier aportación de INFURG se nombra explícitamente.

Se prioriza el adulto y se conservan las particularidades pediátricas, del embarazo y de la inmunodepresión descritas en las fuentes. **«No especificado»** indica un dato ausente en el fragmento, no que sea innecesario para una pauta completa.

Se han leído íntegramente ambos PDF. Los originales permanecen locales; el repositorio publica solo Markdown. «SEN 2025» e «INFURG-SEMES 2012» identifican los archivos aportados, que no incluyen portadas o créditos editoriales generales completos.
